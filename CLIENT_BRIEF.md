## Типографіка (перевірено 19.08.2026)
Правила, яких треба дотримуватись при будь-яких правках тексту:
- жодного однолітерного слова в кінці рядка — прив'язуємо нерозривним пробілом
  (`\u00A0`): «в Україні», «з апостилем», «і ми»;
- тире ніколи не завершує рядок — зв'язане з наступним словом («— 5–7 днів»);
- жодного рядка з одним словом — останні два слова абзацу зв'язані нерозривним пробілом;
- складні слова через дефіс мають нерозривний дефіс `\u2011` («онлайн‑підписання»);
- діапазони й час загорнуті у `<span class="nowrap">` («9:00–17:00»);
- `h1,h2` та `.hcard h3` — `text-wrap:balance`; `p, li, small, h3, h4` — `text-wrap:pretty`;
- телефони та кнопки — `white-space:nowrap`.

Перевірка автоматизована: `node audit.mjs http://localhost:3000 <ширина>` виводить
усі порушення (зависла літера / тире / рядок з одного слова). Станом на 19.08.2026

## SEO, соцмережі та іконки (26.08.2026)

Домен у всіх абсолютних посиланнях — `https://doverka.eu`. Якщо домен зміниться,
правити константу `ORIGIN` у `build-seo.mjs` і перезапустити скрипт.

### Що додано в `<head>` обох сторінок
Блок між маркерами `<!-- ===== SEO … ===== -->` **генерується** `build-seo.mjs` —
руками в HTML не редагувати, зміни вносити в конфіг `PAGES` усередині скрипта.

- `canonical` (`/` для української, `/ru.html` для російської);
- `robots: index, follow, max-image-preview:large` — дозволяє великі прев'ю картинок у видачі;
- `hreflang` переписано на **абсолютні** URL (раніше були відносні `/index.html` — Google такі ігнорує);
- повний Open Graph + Twitter `summary_large_image`;
- іконки: `favicon.ico`, `favicon.svg`, `apple-touch-icon`, `site.webmanifest`, `theme-color #1f477b`;
- `preload` героя + `fetchpriority="high"` (LCP-кандидат на всіх ширинах).

### Картка для соцмереж
`images/og-cover.jpg` (UA) та `images/og-cover-ru.jpg` (RU), 1200×630, ~95 KB.

**Свідомо без фото адвоката** — при шері в Telegram, Facebook, WhatsApp чи LinkedIn
має бути видно логотип `doverka.eu`, а не портрет. У картці: знак + логотип, заголовок
Oswald, підзаголовок, контактний рядок, синій градієнт із зерном і жовтим акцентом.
Генерується `gen-og.mjs`; `seo-audit.mjs` окремо перевіряє, що в `og:image` не потрапило
щось на кшталт `bogdan-*`/`portrait`.

### Структуровані дані (JSON-LD)
Граф у кінці `<head>`: `WebSite`, `LegalService/ProfessionalService` (адреса, години,

`aggregateRating` свідомо немає — поки немає реальних відгуків, вигадувати рейтинг не можна.

### Генератори сторінок (27.08.2026)
`derive-page.mjs` — спільний модуль: `/order` і `/thanks` **виводяться** з
`index.html` / `ru.html`, а не пишуться руками. Шапка, підвал, стилі та спільний JS
не можуть розійтися з головними сторінками. Кожен генератор додає лише своє:
CSS, `<main>` і хвіст інлайн-скрипта.

Порядок збірки після будь-якої правки чинних сторінок:
```
node build-order.mjs && node build-thanks.mjs && node build-seo.mjs
```
`build-seo.mjs` тепер **ідемпотентний** — раніше кожен запуск додавав по порожньому
рядку у кожну сторінку (накопичилось ~14) і одного разу записав літеральні `\n`;
і те, і те прибрано.

Константи `NB` (нерозривний пробіл) і `NH` (нерозривний дефіс) експортує
`derive-page.mjs` як `'\u00A0'` / `'\u2011'` — саме екранованими, бо літеральний
символ у коді легко втратити при копіюванні.

## Сторінка замовлення `/order` (26.08.2026)

Окрема посадкова сторінка з формою **Tally** — під рекламні кампанії.

- `order/index.html` → `/order` (українська), `order/ru.html` → `/order/ru.html`;
- форма: `https://tally.so/embed/wb496g` з параметрами
  `alignLeft=1&hideTitle=1&transparentBackground=1&dynamicHeight=1`;
- заголовок форми схований (`hideTitle`), бо свій `h1` уже є на сторінці;
- фон прозорий — видно білу картку сайту, а не сірий фон Tally;
- висоту підганяє `tally.so/widgets/embed.js` (`dynamicHeight`);
- якщо віджет не завантажився за 6 секунд — показується запасний блок
  із кнопкою на `https://tally.so/r/wb496g` (той самий патерн, що й у Testimonial.to).

**Сторінки генеруються, а не пишуться руками.** `build-order.mjs` бере `index.html` /
`ru.html`, лишає `<head>`, шапку, підвал, стилі та спільний JS, підміняє `<main>` і
переписує посилання під вкладеність (`/images/…`, `/#pricing`, `#order` → `#form`).
Тому будь-яка зміна шапки чи підвалу автоматично доїжджає на `/order` після
перезапуску. Тексти сторінки — у конфігу `PAGES` усередині `build-order.mjs`.

Порядок: `node build-order.mjs` → `node build-seo.mjs`.

### Структура сторінки
Ліва колонка — картка з формою. Права (липка) — «Що буде далі» (4 кроки) і «Скільки це
коштує». Під ними на всю ширину — месенджери та три пункти довіри. Форма Tally коротка
(покрокова), тому нижні панелі винесені з колонки — інакше права колонка вдвічі довша.

### SEO
`build-seo.mjs` тепер знає **чотири** сторінки й розводить `hreflang` по кластерах:
`/` ↔ `/ru.html` і `/order` ↔ `/order/ru.html`. Кластери не змішуються — інакше Google
ігнорує анотацію цілком. Для сторінок замовлення тип `ContactPage` + `BreadcrumbList`,
`FAQPage` немає (FAQ на сторінці немає — скрипт додає його лише коли знаходить розмітку).
Свої соцкартки: `images/og-order.jpg` / `og-order-ru.jpg`.

`seo-audit.mjs` перевіряє всі чотири сторінки й окремо — що `hreflang` кожної сторінки
містить посилання на саму себе (тобто кластер зібраний правильно).

### Локальний сервер
`serve.mjs` тепер віддає `index.html` для шляхів без розширення, щоб `/order`
працював так само, як на хостингу.

### Що вирішити
- **Обкладинка форми в Tally.** У формі стоїть cover-зображення — у вбудованому вигляді
  воно обрізається широкою кремовою смугою з логотипом. Прибрати його в налаштуваннях
  Tally (Cover → Remove) — і картка стане чистішою. З боку сайту це не змінити:
  iframe крос-доменний.

## Форма → Telegram (28.08.2026)
Форма в `#order` на головній надсилає заявки в Telegram через `send-form.php`
(PHP на Hostinger). Побудовано на тому самому шаблоні, що вже працює в проєкті
«Сайт Юрій Хмара» — той самий поділ на `config.php` / `config.example.php`,
пастка для ботів, ліміт по IP, cURL із запасним варіантом через stream
(на частині тарифів Hostinger PHP 7.4 без ext-curl) і `?selftest=1`.

Що передається: `name`, `contact`, `document`, `gdpr`, `lang`, `page`
плюс приховане `website` (пастка). Контакт приймається як телефон (≥7 цифр),
`@nickname` або e-mail — клієнт пише тим, чим уже користується.

Додано в обидві сторінки: чекбокс згоди на обробку персональних даних
(адвокат у Швеції, дані з ЄС — згода обовʼязкова), блок помилки `#form-error`
з підсвіткою полів, які відхилив сервер, і стан «Надсилаємо…» на кнопці.
Після успіху — редирект на `/thanks` (`/thanks/ru.html` з російської), тобто
конверсія має власну URL для рекламних кабінетів.

**Токен у git не потрапляє.** `config.php` у `.gitignore`, створюється прямо
на сервері. У репозиторії лише `config.example.php` із заглушками.

Перевірено: PHP 7.4 і 8.2 (`php -l`), усі гілки ендпоінта під реальним
PHP-сервером (405 / 422 по кожному полю / пастка → тихий 200 / ліміт → 429 /
відсутній config → 500), і браузерний прохід — валідація, пастка, помилка
доставки, обидві мови. Токен не зʼявляється в жодній відповіді.

Аудити `audit.mjs` і `layout-audit.mjs` навчено ігнорувати `.form-trap`
(вона навмисне за межами екрана), а перевірка тап-таргетів тепер міряє
чекбокс разом із його `<label for>` — активна зона це пара, а не сам квадратик.
Рядок згоди отримав вертикальні відступи, щоб зона була 41px, а не 21px.
